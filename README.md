This repository contains my complete Verilog HDL implementation of Digital Logic Design concepts, starting from basic logic gates and progressing to finite state machines (FSM). It covers combinational and sequential circuits with proper testbenches and simulation, focusing on building strong RTL design fundamentals required for VLSI roles.

This repository showcases my hands-on work in digital design using Verilog HDL. I have implemented all core DLD concepts in a structured way, starting from basic logic gates and gradually moving towards complex designs like FSMs. The main focus of this work is to strengthen my understanding of RTL design, coding practices, and circuit behavior.

I have used different modeling styles such as behavioral, dataflow, structural, and gate-level modeling to understand how the same circuit can be described in multiple ways. This helped me improve my coding approach and write better and more optimized Verilog modules.

Special attention is given to writing proper testbenches and verifying outputs through simulation. I have also explored how circuits behave in edge conditions such as don’t care (X) and high impedance (Z) states, which are important for real hardware design.

The repository is well organized into sections like basic gates, combinational circuits, sequential circuits, and FSM designs. It also includes a simple guide (PDF) explaining how to run the code using simulation tools like ModelSim or by using Vivado.

Overall, this project reflects my strong interest in VLSI and digital design, and my effort to build a solid foundation required for roles in RTL design, verification, and hardware development.
